# Enterprise Network Design with ASA Firewall and DMZ

## Project Overview

Designed and implemented an enterprise network for EvolveIT Tech including VLAN segmentation, EtherChannel, Cisco ASA firewall deployment, DMZ architecture, and secure Internet access.

## Technologies Used

- Cisco Packet Tracer
- Cisco ASA Firewall
- VLANs
- EtherChannel
- PortFast
- BPDU Guard
- DHCP
- PAT
- Static NAT
- ACLs
- SSH

## Key Features

### Internal Network

- Management VLAN
- Operations VLAN
- Marketing VLAN

### Security

- Cisco ASA Firewall
- DMZ Web Server
- Access Control Lists
- AAA Authentication
- Secure SSH Access

### Availability

- EtherChannel Redundancy
- Spanning Tree Security
